# Claim boundary for Deform360 action-kernel evidence

Supported by the retained development and reserved-object runs:

- action-conditioned, 32-frame tactile-response forecasting on real Deform360
  robot/tactile episodes;
- source-fitted improvement over persistence;
- degradation under future-action permutation;
- same-object adaptation from other episodes and confirmation on four objects
  excluded from method development.

Not supported:

- dense 4-D object-geometry prediction;
- zero-shot prediction on an object without source episodes;
- strict individual counterfactuals;
- calibrated joint trajectory uncertainty;
- the source-selected guarded deployment rule;
- safety, state of the art, or automatic paper acceptance.
