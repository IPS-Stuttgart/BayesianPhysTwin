# Reward-aligned Slingshot native qualification

The terminal v3 calibration actions support a narrower, outcome-aligned native
contract for a future protocol. All 1,024 action processes were ordinary. All
128 worlds reproduced the same causal prefix, exact world realization, fixed
endpoints, and independent incumbent reward within the pre-existing 0.001
reward margin.

One world did not reproduce the complete rigid-object trajectory within 0.5
mm. That failure remains part of v3 and is not reclassified. For a successor,
the positional difference is instead an observed simulator-process variable:
the policy-value estimand is reward under one native process realization, and
the incumbent reward is the mean of its two independently executed duplicate
slots. This aligns admission with the decision quantity while retaining the
state divergence as a reported execution-risk diagnostic.

This qualification uses only the already-open v3 calibration source. It does not score v3,
reopen its roster, or authorize v4 execution automatically. V4
must use new disjoint worlds, preserve the 0.001 reward-repeatability gate, and
freeze its method before any new future is generated.
