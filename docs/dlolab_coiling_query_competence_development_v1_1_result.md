# DLO-Lab Coiling Development v1.1 Result

V1.1 is terminal without a coiling competence conclusion. The replacement
correctly passed the one-rod material binding, completed and sealed the first
native material world, and then failed while writing its QA receipt: one
rederived comparison was a NumPy boolean that the canonical JSON writer refuses
to serialize. Eight worlds were never run. No complete source bank, Bayesian
value calculation, or development gate exists.

The sealed first world independently rederives as native-qualified on every
frozen check. Its seven unique action rewards range from `0.0881246794` to
`0.1106086053`, so the fixed bank does produce nontrivial action variation in
that one world. That is useful design evidence only. It cannot establish
cross-world decision headroom, prefix information value, transfer, or a method
gain.

Because the failure occurred after one world outcome existed and v1.1 forbids a
further replacement, the material-grid study is closed. Neither the original
root nor the v1.1 root will be rerun. A future coiling experiment must ask a
different, prospectively frozen question on disjoint worlds and cite this one
opened world as development data. The next permitted direction is therefore a
separate off-grid state/material transfer screen, not completion of the missing
v1.1 denominator.
