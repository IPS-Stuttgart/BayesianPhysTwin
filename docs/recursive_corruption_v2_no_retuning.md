# No-retuning rule

The fresh evidence roster `100000:100200`, all method definitions, all guard
thresholds, all corruption generators, both primary endpoints, all co-equal
criteria, and all review margins are frozen by the source branch before the
result is retained in the paper repository.

After the first complete fresh-roster result is opened, no threshold, method,
condition, seed, endpoint, margin, weighting, or exclusion may be changed on
that roster. A change requires a new benchmark version and a new untouched
roster; the original result remains retained.
