# Task-aware Value-of-information Source Result

## Decision

**The preregistered selector and task-headroom gates failed before truth-world
generation. No task-aware source-value result was produced.**

The sole registered attempt successfully generated and sealed the complete
15-world particle bank: five matched-reset probe branches and nine matched-reset
task-action branches. All 14 native branches passed the frozen clamp, geometry,
height, and exact snapshot-restoration checks.

The generic full-latent selector chose `fast_conical_twist`, with estimated
mutual information of 0.376714 nats. The task-aware selector chose `null_hold`.
Its expected downstream Bayes loss was exactly 0.007916362653302937 for every
probe because every material-world and goal combination selected the zero-offset
task action. There was therefore no task value for any material observation:

- one distinct bending-conditioned oracle action was observed for each goal,
  below the required two;
- all 45 particle-world/goal oracle choices were action index 4, the zero-offset
  action;
- oracle gain over the goal-conditioned best fixed action was 0%;
- the task-aware probe was null and had 0% expected-risk gain over the null,
  fixed, and generic-information probes.

The frozen information boundary stopped the run at this point. No truth-world
probe observation, decision, truth future, reward comparison, or source score
was generated. The output root is terminal and will not be retried.

## Interpretation

This is a controlled task/action-headroom negative, not a runtime failure and not
evidence that task-aware value of information is generally ineffective. The
probe family can distinguish the frozen bending/twisting particles, but the
registered vertical tip-height task cannot use that information because the
registered action family has one common optimum.

A descriptive audit of the sealed particle bank explains the gate result. Across
the nine actions, the mean within-world change in the scored tip height was only
2.448 micrometres, and its maximum was 8.174 micrometres. The largest material
span for one action was 13.034 micrometres. Those changes were too small to alter
the optimal action after the frozen effort penalty, while the three requested
tip heights were 0.53, 0.58, and 0.63 m and the achieved tip height stayed near
0.501 m.

The useful methodological lesson is prospective: an active-information study
must first demonstrate control-conditioned task headroom, not merely parameter
identifiability. Maximizing latent mutual information selected a nonnull twist
probe here, but that information had zero value for the frozen downstream
decision. This cleanly separates "informative about the model" from "useful for
the task."
