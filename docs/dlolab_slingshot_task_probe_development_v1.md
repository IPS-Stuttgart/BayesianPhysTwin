# Slingshot Task-valued Probe Development Screen

This is a bounded development screen, not a scientific evaluation or a retry of
the closed 25%/50% early-pull protocol. It uses only the already-open x-offset
zero material slice and its already-open seven-action reward table.

The old passive prefix and old 50% front-loaded prefix are fixed controls. Two
new prefix-only probes move 60% or 70% of the incumbent second macro translation
into the first macro and subtract the same vector from the second. They preserve
the summed translation, all rotations, the 0.1 m translation envelope, and the
public native simulator. No task future is generated.

For each probe, the screen evaluates expected downstream Bayes reward under the
existing 2 mm independent plus 5 mm shared-bias observation model. It also
reports MAP reward and full-latent mutual information. Common frozen noise draws
are used across candidates.

Development feasibility requires all four new native prefix batches to pass,
the task-valued selector to choose a new probe, at least 0.005 reward gain over
the blind action, at least 0.001 over the old 50% probe, and at least 25% of the
finite-slice oracle headroom. Passing permits only design of a new prospective
source protocol. It does not authorize truth futures, fresh data, a controller
claim, or automatic promotion. Failure closes these two new probes without a
retry.
