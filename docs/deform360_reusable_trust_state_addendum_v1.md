# Deform360 reusable-twin state addendum v1

This addendum freezes the episode-state hypothesis for the admitted penguin arm
before any source future-object outcome is used for physical-parameter fitting.

The rejected free-vertex MAP initializer reduced frame-zero readout error by only
about 1--2 mm while introducing severe local spring prestrain, unstable official
Warp responses, and one failed controller attachment. It is therefore not a
physically credible reusable-twin state.

The frozen replacement preserves one object graph and its rest lengths exactly.
Each episode may apply only a deterministic proper rigid placement to that graph,
found by a frozen six-step appearance-aware ICP with PCA multistart and the
pre-existing deterministic translation-anchor candidates as fallbacks;
the observed frame-zero geometry is represented by an external probabilistic
readout whose covariance includes assignment-mixture spread. No simulator
residual, post-initial object frame, target tactile signal, source future outcome,
or held-out media was used to choose this policy.

All six source episodes must pass the existing frame-zero gates, produce finite
official Warp rollouts at the fixed reference parameters, keep p99 Warp edge
strain at or below 50%, and admit the frozen 3 cm dynamic contact attachment. A
single failure rejects this reusable penguin arm and returns exact persistence.

The addendum does not claim improved prediction. It only defines the final
source-only state admission test before the physical grid and future outcomes are
opened.
