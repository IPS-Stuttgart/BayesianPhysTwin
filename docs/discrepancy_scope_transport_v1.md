# Diagnose–Decompose–Transport: hierarchical discrepancy scope

## Scientific question

A learned simulator residual can improve prediction without being one reusable
physical object.  It may encode:

- a discrepancy shared across objects and simulator backends;
- an object-specific discrepancy that survives a backend change;
- a backend-specific discrepancy that survives an object change;
- an object–backend interaction that is local to one pairing; or
- an unregistered mechanism outside the supplied cause family.

The method therefore joins two previously separate certificates:

1. **interventional cause diagnosis**: explain, transport a query quotient, request
   a target-identifying probe, or abstain; and
2. **transport scope diagnosis**: determine which domain-shift invariances are
   supported and descend to the strongest directly validated transport tier.

No point cause is forced when several explanations remain compatible.

## Finite scope family

Let `o` denote physical object identity and `b` the simulator backend.  The
registered exact-coefficient scope family is evaluated on four axes:

| Axis | Meaning |
|---|---|
| `same_object_same_backend` | local reproduction |
| `same_object_new_backend` | backend invariance |
| `new_object_same_backend` | object invariance |
| `new_object_new_backend` | simultaneous object/backend invariance |

The exact-coefficient signatures are:

| Scope | local | new backend | new object | double shift |
|---|---:|---:|---:|---:|
| shared physics | pass | pass | pass | pass |
| object-specific, backend-stable | pass | pass | reject | reject |
| backend-specific, object-stable | pass | reject | pass | reject |
| object–backend local | pass | reject | reject | reject |

Only observed, prospective, target-selection-free evidence constrains this
finite family.  Missing axes remain missing.  If several signatures are
compatible, the output is set-valued.  If no signature is compatible, the
result is `none_of_the_above` rather than a repaired label.

These labels describe invariance over registered tests.  They are not claims
that nature has a unique additive decomposition.

## Tiered transport

For one requested domain shift, the reusable object is selected in this order:

1. exact residual coefficients;
2. a held-query effect;
3. a fixed residual direction with one scalar amplitude;
4. uncertainty structure only;
5. the fitting procedure only; or
6. exact fallback.

A tier is considered only when it has **direct evidence on the requested
axis**.  A success on a same-object backend shift is not extrapolated to a new
object plus new backend.

Procedure-only support never deploys a correction.  It means that the
registered fitting procedure may be run on admissible target-side source data;
until that refit is complete and separately qualified, the caller-owned
fallback is returned.

## Composition with cause diagnosis

The portable target decision from
`explain_transport_probe_abstain_v1` determines whether any transport tier may
be used:

- `explain_and_transport` or `transport_without_cause`: consult the tier
  evidence;
- `probe_then_reassess`: retain exact fallback until the registered response is
  observed and the entire diagnosis is recomputed;
- `none_of_the_above`: no registered tier may be promoted;
- `partial_only_fallback` or `abstain`: exact fallback;
- `no_detectable_error`: make no correction.

This order is essential.  Strong transfer statistics cannot rescue an
inadequate physical cause family, and a unique cause label is unnecessary when
the held-intervention query is invariant over the compatible explanation set.

## Controlled result

The deterministic study separates all four registered scope signatures.  It
also verifies:

- shared exact coefficients can be transported over a registered double shift;
- an object-specific correction transports across a tested backend change but
  descends to procedure-only transfer across objects;
- an unmodeled cause overrides apparently favorable transfer evidence;
- a non-monotone transfer pattern outside the finite family fails closed; and
- content-addressed records reject tampering.

| matching DLO4/DLO5 source refit | frozen procedure | **+6.803%, 28/28 wins** |

The finite-family diagnosis is therefore:

> **The tested DLO3 correction is object-specific but backend-stable on the
> observed axes.  Across DLO identities, the strongest supported reusable
> object is the fitting procedure—not the coefficient vector.**

This is a scientifically useful negative result.  It rejects the tempting
“universal missing-physics operator” interpretation while retaining a more
precise claim about what transfers.

The classification uses retrospective public development evidence.  It has no
bound real cause-diagnosis artifact, so the operational result is
`evidence_only` and exact fallback remains required.

## Claim boundary

The certificate is exact for a finite registered scope family and direct
tier-evidence contracts.  It does not prove an unrestricted causal
decomposition, nonlinear closure, arbitrary-object or arbitrary-backend
transport, target calibration, online robot safety, or state of the art.
