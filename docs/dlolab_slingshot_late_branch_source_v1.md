# Later Prefix and Final-Motion Source Screen

This new source-only screen asks whether informative later observations still
leave enough control authority for Bayesian action selection. The earlier
300-step belief study, early-pull miss, contact/force value misses, and stopped
vertical-path screen remain closed. No previous result or tolerance changes.

Use the nine already-open material particles at nominal placement (indices
9 through 17 of the frozen 27-particle source bank), with their tensor prior
weights renormalized. Keep native physics, -3 N action force, release at step
700, and the full 900-step native reward. Every candidate shares the first
two macros of source control 5. Branch at step 500, using only rod nodes
3/6/8 and the sphere center at frames 139, 319, and 499. The target cube is
not observed. This is the same 12 position-observation budget, shifted later,
not a claim of equal latency to the earlier policy.

The seven unique final-macro actions are: retained source control 5; zero
final translation; half final translation; planar steering minus 20 degrees;
planar steering plus 20 degrees; retained source control 6; and source
control 5 with final yaw increased by 0.4 radians. Unmentioned components
stay unchanged. Zero translation is not a full no-action command because
rotation remains. Slot 7 duplicates slot 0. All commands must satisfy the
existing 0.1 m translation-ball and 1 radian component limits without tuning.

First verify the already-open prefix's whitened stretching secant norm is
at least 1 under the fixed 2 mm independent plus 5 mm shared-bias observation
model. Then run three fresh nominal batches of this exact new bank. All
actions must have cross-process reward range at most 0.00025 and coordinate
range at most 1 mm. These are engineering budgets, not confidence bounds.
Only then run the other eight material worlds once each. Total budget is
11 CPU batches / 88 trajectories. The first nominal batch supplies source
values; repetitions are qualification only, not cherry-picked or averaged.

Every batch must preserve the full 500-frame common prefix within 1 micrometre,
fixed endpoints within 1e-9 m, and exact command/native reward arithmetic.
The duplicate and retained source controls 5/6 must agree with their respective
reference trajectories within 1 mm and reward within 0.00025. This is a new
prospective contract, informed by a separate numerical audit, and does not
waive the stopped path screen's stricter contract. Exact software fallback
means returning the cached incumbent artifact unchanged, not claiming a new
native simulation is byte-identical. No deployed guard is evaluated here.

Once all native admission/repeatability gates pass, seal the full source bank
before integrating expected rewards. Use the exact nine-world prior and
8192 shared-bias/noise draws per world, seed 260912. Compare bias-aware
posterior-mean action selection with the best fixed action, MAP, ignored
shared bias, and the world oracle. This is deliberately an optimistic
finite-model source screen, not independent control performance or calibrated
real sensing. Monte Carlo standard errors concern integration only.

Subtract a fixed 0.0005 paired numerical margin from each primary gain.
Require adjusted gain over the best fixed action at least 0.005 and at least
10% of its reward above the native zero-control value; adjusted gain over MAP
at least 0.002; and adjusted gain over ignored shared bias nonnegative.
Also require the posterior reward to be no worse than the original seven-
action source bank's best fixed reward within the same 0.0005 margin. All
checks must pass. This avoids crediting observation value from a deliberately
weakened fixed comparator. The margin is not a statistical guarantee.

The implementation, all tasks, commands, source references, observation and
arithmetic choices are hash-bound before native initialization. A failed
native gate or runtime attempt is retained and terminal; no retry, replacement,
action-grid revision, or threshold change is allowed in this study. All later
workers independently rederive previous admissions and the nominal repeat gate.
