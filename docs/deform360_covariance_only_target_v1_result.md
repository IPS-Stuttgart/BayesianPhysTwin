# Deform360 covariance-only target v1 metadata-gate result

The v1 metadata gate terminated before target-roster creation. Its fixed
32-object panel contained a released episode with malformed `nonprehensile`
metadata, which violated the registered strict-enum validator.

The failure occurred after opening only the selected `metadata.json` files. No
camera media was decoded; no tactile or robot array, geometry, track annotation,
prediction, or target outcome was opened. No object was replaced. The result is
bound by
`results/science/deform360_covariance_only_target_v1/metadata_gate_failure.json`,
and all 32 metadata-touched objects are bound by the companion hash-only
exclusion artifact.

An outcome-blind names-only audit found only two untouched volumetric-name
objects after excluding this panel. A wholly new balanced 24-session protocol is
therefore infeasible. The separately locked v1.1 amendment reuses the exact panel
and changes only treatment of the nonselective field: malformed
`nonprehensile` values are recorded as invalid but cannot affect the target
assignment. Strict `action` and `bimanual` validation, the factorial quotas, the
covariance-only method, and every no-replacement rule remain unchanged.
