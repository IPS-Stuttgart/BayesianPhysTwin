# PokeFlex action-robust official-18 V4 protocol

## Purpose

This protocol freezes the direct PokeFlex state-of-the-art test before the five
official validation takes absent from the licensed public archive become
available. It binds the source-derived all-object V4 scale map, the exact
hard-coded upstream validation list, the official evaluator and checkpoint, and
the immutable retrospective public-13 result.

The protocol digest is
`112a34e3af11f7fde44fa70de6b712d8b906ba81ea287b4897ad4a13692fed26`.

## Cohort

The exact official split contains eighteen takes. Thirteen are already opened
and are imported only through the checksummed V4 result artifact. These five
remain prospective:

- `Pillow_T8`
- `3dPrintedCylinder_T7`
- `3dPrintedHeart_T14`
- `Sponge_T10`
- `3dPrintedPizza_T13`

No replacement take is permitted. An unavailable or technically failed take
remains in the accounting.

## Acquisition Boundary

Author access must first produce a source-admission manifest that binds the exact
take IDs, archive and member hashes, stream inventory, episode length, and
compatibility with the registered evaluator. This source lock is created before
prediction and before any target mesh is decoded.

Predictions use observations and robot history only through frame `f-1`. All
five prediction seals, from one clean implementation revision, must pass a
barrier before any target mesh is opened. Unsupported frames return the released
checkpoint byte for byte. Parameters, object multipliers, scoring, and gates may
not change after this lock.

## Two Claims

The evaluation deliberately separates two questions.

### Direct full-split benchmark

The released checkpoint must reproduce the published `6.498 mm` result within
`0.0005 mm`, the precision implied by the three-decimal publication. V4 must be
below the published checkpoint and the frozen global correction, with negative
97.5% object-bootstrap upper differences against both.

Passing this gate supports a direct improvement on the exact published split.
It does not make the experiment fully prospective because thirteen outcomes were
already open.

### Prospective missing-five transfer

Across the five previously unavailable takes, V4 must improve the object-balanced
mean, have no object-level regression against the released checkpoint, and have
a negative 97.5% object-bootstrap upper difference.

Passing this gate supports prospective transfer to the only untouched portion of
the official split. The paper must report this separately from the mixed-exposure
full-18 result.

## Current State

The method, evaluator, cohort, custody, and gates are frozen and tested. The
experiment remains unrun because the five exact author-supplied takes are not in
the licensed public download. No PokeFlex future artifact and no Deform360
held-v8 artifact or process was accessed while creating this lock.
