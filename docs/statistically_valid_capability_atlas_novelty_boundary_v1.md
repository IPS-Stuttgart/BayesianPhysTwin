# Novelty and attribution boundary

Split conformal prediction, conformal risk control, and data-driven decision calibration are established methods. The contribution of this repository is not a claim to have invented conformal decision making.

The intended contribution is their composition with:

- a quotient-induced ambiguity set over complete physical beliefs;
- exact finite-action pairwise regret envelopes;
- continuous affine task families represented as exact polyhedra;
- explicit task-objective uncertainty via support functions;
- one calibration score per independent physical object or trajectory; and
- complete identity-preserving fallback outside the calibrated capability atlas.

Any paper must cite the relevant conformal and risk-control literature and state the exchangeability and marginal-validity boundary explicitly.
