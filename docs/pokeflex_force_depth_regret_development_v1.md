# PokeFlex Force-Depth Regret Development v1

## Status

This post-open development study is complete. The source-only result is
positive, but the stronger nine-object evaluation fails the locked transfer
gates. The eight PokeFlex target objects remain sealed and no target protocol
is authorized from this method.

The candidate bank was generated by the frozen independent-depth runner. It
projects the causal Kinect state innovation into force- and action-reachable
local fields, then uses only D405 observations from frame `f-1` to score a
candidate prediction for frame `f`. No target-frame observation enters a
candidate feature or decision.

## Method

The bank contains four physical fields, four object-relative support radii,
and four nonzero update gains. A target-free feature vector combines D405
candidate regret, candidate geometry, update magnitude, measured force and
tool-motion summaries, robust weights, association spread, and D405 static
calibration residuals.

Evaluation uses nested leave-one-object-out cross-fitting:

1. the outer fold holds out the evaluation object;
2. candidate regret is fitted only on the remaining objects;
3. an inner object holdout calibrates the winner's-curse correction caused by
   selecting the minimum predicted-regret arm;
4. an arm is applied only when its candidate UCB plus selector correction is
   below zero;
5. rejection returns the released Kinect checkpoint prediction exactly.

The evaluator also records fixed-arm, uncalibrated point-selector, and oracle
controls. These are diagnostics, not alternative confirmed deployments.

## Results

| Evaluation | Method | Object-balanced CD_UL1 | Relative improvement | Object result |
| --- | --- | ---: | ---: | --- |
| Five source objects | Released checkpoint | 4.901 mm | reference | - |
| Five source objects | Nested regret guard | 4.756 mm | **+2.96%** | 4 wins, 1 tie |
| Five source objects | Candidate-UCB control | 4.677 mm | +4.57% | 4 wins, 1 tie |
| Five source objects | Candidate-bank oracle | 4.442 mm | +9.36% | diagnostic ceiling |
| Nine opened objects | Released checkpoint | 4.863 mm | reference | - |
| Nine opened objects | Nested regret guard | 4.883 mm | **-0.41%** | 2 wins, 5 ties, 2 losses |
| Nine opened objects | Candidate-UCB control | 4.928 mm | -1.33% | 5 wins, 2 ties, 2 losses |
| Nine opened objects | Predicted-mean selector | 4.886 mm | -0.47% | 6 wins, 3 losses |
| Nine opened objects | Candidate-bank oracle | 4.488 mm | +7.72% | diagnostic ceiling |

On the source-only fold, the guard accepts 315 frames; 296 improve and 19
regress, for a 6.03% false-safe rate. Candidate-upper coverage is 89.27%, and
all registered source gates pass.

On the nine-object fold, the guard accepts only 57 frames; 41 improve and 16
regress. The false-safe rate rises to 28.07%. `3dPrintedPyramid` regresses by
10.54%, producing a net 0.41% object-balanced regression despite 95.25%
candidate-upper coverage. The regression therefore is not explained by
undercoverage of individual candidate UCBs alone; the object-dependent
candidate ranking and selector correction do not transfer.

## Fixed-Arm Control

The maximin fixed-arm control is safer but too weak. In the nine-object
leave-one-object-out evaluation it improves eight objects, regresses one by
1.27%, and yields only 0.43% object-balanced improvement. The arm selected on
all opened objects is the smallest tested correction:

```text
checkpoint_force_parallel_local_state_relative_0.25_residual_scale_0.125
```

This arm improves all nine opened object means when assessed after selection,
but that is post-selection development evidence. Its cross-object result fails
both the 1% improvement gate and the 1% worst-object-regression gate. The more
aggressive mean-selected fixed arm reaches 1.83% but regresses the held-out
pyramid by 7.66%.

## Interpretation

Measured force and action reachability form a useful inductive prior: they
produce a positive 2.96% source result and a nontrivial 7.72% all-opened oracle.
However, D405 candidate regret is not an object-invariant proxy for hidden
Kinect-checkpoint regret. Adding an independent depth camera does not by itself
identify whether a coherent candidate displacement is true object motion or a
sensor/model bias.

The next method should not tune another per-frame camera/depth selector on
these opened objects. The evidence instead supports:

- a bias-aware belief update with an explicit object/common-mode term;
- action- and contact-conditioned support as a prior over reachable state
  modes;
- regret guarantees relative to an unchanged baseline;
- exact fallback when independent evidence is insufficient;
- fresh-object evaluation only after the selector passes object-level transfer.

## Claim Boundary

- This is post-open method development, not prospective confirmation or a
  PokeFlex state-of-the-art claim.
- Calibration outcomes were used only in the declared all-opened exploratory
  fold after the earlier no-refit calibration result had already failed.
- No target archive, frame, mesh, or outcome was inspected.
