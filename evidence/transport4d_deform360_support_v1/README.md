# Transport4D frozen-split carrier support

A target-closed file-identity audit retained 15 supported calibration objects and 33 supported confirmation objects from the previously frozen Deform360 split. The registered minimums are therefore met without moving or replacing any object. Nineteen objects remain support-negative for insufficient robot-complete episodes and three for tactile recording-count mismatch.

Only metadata, directory names, file names, and file sizes were read. The committed compact result stores a content hash of each full carrier manifest; the complete per-file manifest remains bound to the immutable Actions artifact. Numerical confirmation is still unauthorized.
